## Visão geral

**CSP com hash.** `scripts/csp-hash.mjs` roda no `postbuild`: lê cada página de `dist/`, calcula o SHA-256 de cada script inline e escreve a CSP de ADR-011 em `dist/_headers`. Hoje são 7 hashes:
- o boot de idioma e tema;
- o carregador de ilhas do Astro;
- os pequenos scripts que o Astro embute no HTML (copiar, abas, comandos).

O ADR previa só o hash do boot, mas o build embute outros scripts. Calcular todos no pós-build mantém o `script-src` sem `'unsafe-inline'` e sem hash desatualizado.

**`netlify.toml`.**
- Build com Node 24.
- `X-Content-Type-Options`, `Referrer-Policy` e `Permissions-Policy` em todas as rotas.
- Cache imutável em `/_astro/*`, onde ficam JS, CSS e fontes com hash.
- O HTML fica com o cache padrão da Netlify. Um segundo `Cache-Control` seria concatenado ao de `/_astro/*`, e o teste garante que existe só um.
- Redirecionamento 404 de `/en/*` para a página em inglês.

**Páginas 404.** `/404.html` (pt-BR) e `/en/404/` (en) usam o mesmo cabeçalho e rodapé. Elas são `noindex`, não têm canonical nem alternates, e as âncoras do cabeçalho levam de volta à página inicial (`/#instalar`, `/en/#instalar`).

**Verificador de links.** Agora também parte das duas 404, que nenhuma página linka. Isso resolve o R-02 do REVIEW-T-03.
