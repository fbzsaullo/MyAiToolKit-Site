## Visão geral

`npm run sync:kit` lê o kit pela pasta irmã (`KIT_PATH`) ou por clone raso (`KIT_REPO`) — os dois caminhos geraram snapshots idênticos. O snapshot tem os 12 comandos, a versão `0.1.0` e o commit do kit (`10bb848`). O teste de sincronização falha com instrução clara quando o snapshot fica desatualizado (provado com teste negativo) e é pulado quando o kit não está disponível, como no build da Netlify.
